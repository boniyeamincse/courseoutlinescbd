01 / L2 SCOPE & OBJECTIVES

L2 Analyst-এর গভীর অনুসন্ধান ক্ষমতা

কোর্স শেষে যা করতে পারবে

  • L1 থেকে escalated জটিল alerts-এর রুট কজ শনাক্তকরণ
  • MITRE ATT&CK ম্যাপিং অনুযায়ী থ্রেট হান্টিং পরিচালনা
  • Sigma detection rules তৈরি ও SIEM-এ ডেপ্লয়মেন্ট
  • Endpoint forensic artifacts (MFT, Shimcache, Prefetch) বিশ্লেষণ
  • PCAP এবং Network metadata (Zeek/Suricata) নিরীক্ষণ
  • Incident containment playbooks ও RCA রিপোর্ট তৈরি

কাদের জন্য

SOC L1 Analysts, Junior Incident Responders, Security Engineers যারা L2 বা Tier 2 পদে উত্তীর্ণ হতে চান।

শুরুর প্রস্তুতি

SIEM architecture, Windows Security Event IDs, Linux logs, এবং মৌলিক 네트워크 প্রটোকল জ্ঞান আবশ্যক।

02 / ADVANCED CURRICULUM

১২টি ক্লাসের বিস্তারিত আউটলাইন

প্রতিটি ক্লাসে deep technical concepts + real case investigations

CLASS 01Deep Dive · 60 min

L2 Investigation Framework & Escalation Intake

  • L1 handover validation ও scoping
  • Hypothesis-driven investigation পদ্ধতি
  • Evidence integrity ও chain of custody
Lab

Escalated case review করে investigation hypotheses তৈরি।

CLASS 02Endpoint · 60 min

Advanced Windows Event & Sysmon Analysis

  • Sysmon Event ID 1 (Process), ID 3 (Network), ID 8, 10 (Injection)
  • Parent-Child process anomalies ও LOLBins
  • PowerShell Script Block Logging & Obfuscation decoding
Lab

Obfuscated PowerShell execution deobfuscation ও tracking।

CLASS 03Endpoint · 60 min

Windows Forensic Artifacts for SOC

  • Prefetch, Amcache, Shimcache & Shellbags
  • Registry run keys, Scheduled tasks & Services persistence
  • USN Journal ও $MFT basics
Lab

Evidence package থেকে execution evidence ও persistence প্রমাণ করা।

CLASS 04Linux · 60 min

Linux Server Security & Auditd Investigation

  • Auditd logs, auth.log, journalctl deep-dive
  • Linux persistence (cron, systemd services, SSH keys)
  • Privilege escalation techniques (SUID, sudo exploits)
Lab

CLASS 05Network · 60 min

Network Telemetry & Traffic Analysis

  • Zeek/Bro metadata & Suricata IDS alerts

  • TLS/SSL anomalies ও SNI inspection
Lab

CLASS 06Identity · 60 min

Active Directory & Kerberos Attacks

  • Kerberoasting, AS-REP Roasting ও DCSync detection

  • Golden/Silver Ticket verification
Lab

CLASS 07Malware · 60 min

Malware Triage & Sandbox Analysis

  • Static analysis basics (hashes, strings, PE headers)
  • Dynamic sandboxing (Any.Run, Hybrid Analysis)
  • Extracting C2 URLs, IP addresses ও dropper behaviors

CLASS 08Threat Intel · 60 min

Threat Intelligence (CTI) & MITRE ATT&CK

  • OpenCTI, MISP & AlienVault OTX integration
  • Pyramid of Pain ও TTPs বনাম Hash/IP
  • Mapping alert sequences to MITRE tactics
Lab

CLASS 09Hunting · 60 min

Proactive Threat Hunting Methodology

CLASS 10Engineering · 60 min
